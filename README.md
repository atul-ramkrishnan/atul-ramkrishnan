# Hi there

Welcome to my GitHub page! Here is a summary of the various projects I have worked on, showcasing my skills in web development, machine learning, algorithms, and system design.

- **[Billbuddy](https://github.com/atul-ramkrishnan/billbuddy)**  
  A simple web application to manage shared expenditures among users. It integrates FastAPI with MongoDB for the backend and React for the frontend, serving as a learning project.

- **[Datalog Engine](https://github.com/atul-ramkrishnan/datalog-engine)**  
  A parser built using Python Lex-Yacc to translate Datalog syntax into an internal representation with Abstract Syntax Trees (AST) for efficient rule and query interpretation. It features an optimized query execution mechanism, capable of handling recursive queries with performance strategies like semi-naïve evaluation.

- **[Dirichlet Neural Network](https://github.com/atul-ramkrishnan/dirichlet-neural-network)**  
  A project exploring the use of Dirichlet distributions in neural networks for interpretable predictions. Based on research papers, this repo includes experiments with Dirichlet, Generalized Dirichlet, and Beta Liouville distributions to improve network compression and overcome Dirichlet limitations.

- **[Lane Detection using CNN-RNN Architecture](https://github.com/atul-ramkrishnan/Lane-detection)**  
  A semantic segmentation model based on the SegNet architecture, designed to identify lanes for self-driving vehicles. The model is enhanced with a Convolutional-LSTM component to analyze the impact of temporal data integration on detection performance.

- **[Ford Fulkerson Algorithm](https://github.com/atul-ramkrishnan/ford_fulkerson)**  
  A greedy algorithm implementation of the Ford-Fulkerson method to solve the maximum flow problem. It finds the maximum flow that can be transported from a source vertex to a sink vertex in a network, adhering to capacity constraints.

- **[Todo App](https://github.com/atul-ramkrishnan/todo)**  
  A simple and intuitive Todo WebApp to help users organize tasks and boost productivity. It allows users to add, edit, delete, and categorize tasks in a user-friendly interface.

- **[Shell Emulator in Python](https://github.com/atul-ramkrishnan/ShellEmulator)**  
  A POSIX-compliant shell emulator that provides a command-line interface to interpret and execute shell commands, run external programs, and manage processes, offering a glimpse into the workings of shell environments.

- **[Warzone Game Implementation](https://github.com/atul-ramkrishnan/Warzone)**  
  A command-line version of the Warzone Game written in Java. It replicates the core mechanics of the popular strategy game while introducing customizable features for enhanced gameplay, supporting human and computer players with various strategies.

- **[Paging](https://github.com/atul-ramkrishnan/Paging)**  
  A project that implements and evaluates four paging algorithms to analyze their performance in managing memory paging. The algorithms include LRU (Least Recently Used), Optimal (Farthest in the Future), Blind Oracle, and a Combined Algorithm that dynamically switches between LRU and Blind Oracle.

- **[Dirichlet Pruning for Neural Network Compression](https://github.com/atul-ramkrishnan/dirichlet-pruning)**  
  An exploration of Dirichlet pruning techniques for compressing neural networks. This project investigates methods for reducing the complexity of neural networks through pruning, specifically targeting the use of Dirichlet distributions in the process.
- **[Link Grabber](https://github.com/atul-ramkrishnan/link-grabber-chrome-extension)**  
  A simple little Chrome extension to store URLs for quick access and future reference. Never lose track of your favorite links again!
  
- **[Music Quality Settings Microservice](https://github.com/atul-ramkrishnan/music-quality-settings-microservice)**

  A Spring Boot microservice for managing music quality settings, including minBitrate and maxBitrate. Features a REST API to retrieve configuration values, leveraging @ConfigurationProperties for centralized property management. Built with best practices in Spring Boot for extensibility and maintainability.

- **[Facemask classification](https://github.com/atul-ramkrishnan/Facemask-Classification)**

  A convolutional neural network (CNN) project to classify images of individuals into five categories: no mask, cloth mask, surgical mask, FFP2 mask, and incorrectly worn masks. The project analyzes multiple CNN architectures, implements bias mitigation techniques, and uses k-fold cross-validation to optimize performance, achieving an accuracy of 85.6%.
